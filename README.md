# Экранный переводчик

Захватывает экран, распознаёт текст и рисует перевод прямо поверх оригинала. Перевод
«прилипает» к тексту: едет при прокрутке и исчезает вместе с ним.

## Для пользователя

1. Распакуйте `ScreenTranslator.zip` в любую папку (например, на рабочий стол).
2. Запустите `ScreenTranslator.exe`.
3. Выберите языки и нажмите **«Начать перевод»**.

Крестик окна сворачивает программу в трей (значок «文A» рядом с часами); выход — правый клик
по значку → «Выход». Настройки сохраняются в `%APPDATA%\ScreenTranslator`, там же `log.txt`.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+T | включить / выключить |
| Ctrl+Alt+R | выделить область |
| Ctrl+Alt+F | весь экран |
| Ctrl+Alt+H (удерживать) | показать оригинал |

Нужен Windows 10 (2004+) или 11. Перевод через Google — нужен интернет.

## Для разработчика

Запуск из исходников:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Сборка `dist\ScreenTranslator\ScreenTranslator.exe` и `dist\ScreenTranslator.zip`:

```
build\build.bat
```

Сборка использует `onnxruntime-directml` (работает на любой видеокарте, ~370 МБ). Версия с CUDA
быстрее на NVIDIA, но весит ~3 ГБ — её удобнее запускать из исходников с `onnxruntime-gpu[cuda,cudnn]`.

## Как устроено

- `app.py` — окно настроек, трей, горячие клавиши, запуск/остановка.
- `capture.py` — dxcam (при неудаче mss).
- `pipeline.py` — фоновый поток: следит за изменениями экрана, запускает OCR + перевод
  в отдельном потоке; уже переведённые строки повторно не распознаёт.
- `tracker.py` — слежение за текстом: при скролле сдвиг кадра считается фазовой корреляцией,
  каждый блок проверяется по своему шаблону.
- `ocr.py` — RapidOCR (PP-OCRv6 мультиязычная; кириллица, корейский и др. — PP-OCRv5),
  на GPU через CUDA или DirectML с фиксированными формами входа.
- `translator.py` — Google (пакетный запрос) или Argos (офлайн), с кэшем.
- `overlay.py` — прозрачное окно поверх экрана, исключённое из захвата.
